4. **防御退行机制 (Sanctuary & Cathartic Regression)**：评估高压成人社会中向无机心纯真虚拟世界寻求情绪疗愈的需求。

### 三、 底层防作弊与防刷分技术架构

1. **作答时长与生理认知节奏分析 (Pacing Analysis)**：
   - 题干字数 25~35 字，心理学认知阅读极限 $\ge 1.2$ 秒/题。
   - 卷面有效作答耗时阈值 $\ge 30$ 秒，极速脚本直接熔断。
   - 作答时间变异系数 $CV_t < 0.08$ 判定为按键精灵或宏脚本。
2. **逻辑互锁与质检测谎陷阱 (Paired Items & Attention Trap)**：
   - 内置注意力质检锚点题（指定选项），选错扣除信度分。
   - 常识逻辑题（将动漫判定为真人纪录片），选错判定非理性作答。
   - 对偶反转逻辑互锁题（两题语义相反），若同选极高或极低则标记矛盾。
3. **直线作答与方差质检 (Straight-Lining & Variance Check)**：
   - 连续同选 $\ge 8$ 题降低信度，$\ge 14$ 题直接废卷。
   - 全卷方差 $< 0.20$ 触发区分度不足警告。
4. **会话签名与防重放 (Cryptographic Session)**：
   - 后端发放带有时间戳加盐签名（HMAC-SHA256）的唯一 `SessionID`。
   - 服务端记录会话生命周期，已评估会话禁止二次提交（HTTP 409）。
5. **速率限制与指纹风控 (Sliding Window Rate Limit)**：
   - 结合客户端 Canvas + 屏幕 + 时区特征哈希与 IP，滑动窗口限流 5 分钟最多 6 次请求。
